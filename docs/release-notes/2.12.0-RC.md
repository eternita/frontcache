# Frontcache 2.12.0-RC — release note

Docs index: [../doc-index.md](../doc-index.md) · All release notes: [README.md](README.md)

Everything that has landed since 2.11.0:

- **The console can be served under a path of a larger site, and bound to one address.** Two new
  launcher settings: `FRONTCACHE_CONSOLE_CONTEXT_PATH` (e.g. `/ops/console`; default `/`) and
  `FRONTCACHE_CONSOLE_HOST` (e.g. `127.0.0.1`; default every interface) — the system properties
  `frontcache.jetty.context-path` and `frontcache.jetty.host` for anything that starts
  `ConsoleJettyServer` itself. The console's pages, scripts and redirects are context-relative, so a
  reverse proxy forwards the path unchanged. Nothing changes for a console started as before.
- **The console's edge list can be made read-only.** `edge-editing = false` in
  `frontcache-console.conf` removes the Edges screen's add / remove buttons and refuses
  `POST /add-edge` and `/remove-edge` with a `403`; `/` then also stops adding a local edge by
  itself on a console with none. For a console whose `urls` your own tooling writes: an edge added
  by hand was monitored and sent the api-key until the next restart silently dropped it. Default
  true — an existing config behaves as before.
